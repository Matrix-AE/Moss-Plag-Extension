| Prompt | 067 — Build the Result Experience |
| Module | `@moss/ui/result-experience` |

Completion screen for deliberately opening and protecting the provider-hosted similarity report. Shows completion time, language, mode, estimated availability, open (with `noreferrer noopener`), copy, rerun, and forget. Warns about bearer-link confidentiality, browser history, clipboard, and that forget does not revoke provider copies. Reports support human review and are not plagiarism verdicts. Never invent percentages, auto-open, guarantee availability, or call the link private.
